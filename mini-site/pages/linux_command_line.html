Ligne de commande Linux : mémento

Ce mémento regroupe les commandes Linux vues en cours de SISR, classées par thème. Pour chaque commande : son rôle et un exemple d'utilisation.

Mémento des commandes Linux
Commande Description Exemple d'utilisation
Navigation et fichiers
pwd Affiche le répertoire courant pwd
ls Liste les fichiers et dossiers ls -l
cd Change de répertoire cd /home/user
mkdir Crée un dossier mkdir projets
rmdir Supprime un dossier vide rmdir projets
touch Crée un fichier vide (ou met à jour sa date) touch notes.txt
cp Copie un fichier ou un dossier cp -r site/ sauvegarde/
mv Déplace ou renomme un fichier mv ancien.txt nouveau.txt
rm Supprime un fichier ou un dossier rm -r vieux_dossier
Lecture et recherche
cat Affiche le contenu d'un fichier cat /etc/hostname
less Affiche un fichier page par page less /var/log/syslog
head Affiche les premières lignes d'un fichier head -n 5 fichier.txt
tail Affiche les dernières lignes (suivi en direct avec -f) tail -f /var/log/syslog
grep Recherche un motif dans un texte grep -i erreur syslog
find Recherche des fichiers dans l'arborescence find /home -name "*.html"
nano Éditeur de texte en ligne de commande nano index.html
Droits et utilisateurs
chmod Modifie les droits d'un fichier chmod 755 script.sh
chown Change le propriétaire d'un fichier chown user:groupe fichier
sudo Exécute une commande avec les droits administrateur sudo apt update
useradd Crée un utilisateur sudo useradd -m alice
passwd Change un mot de passe sudo passwd alice
whoami Affiche l'utilisateur courant whoami
Système, processus et paquets
ps Liste les processus en cours ps aux
top Affiche l'activité du système en temps réel top
kill Arrête un processus à partir de son PID kill 1234
df Affiche l'espace disque des partitions df -h
du Affiche la taille d'un dossier du -sh /var/log
apt Installe ou met à jour des paquets (Debian/Ubuntu) sudo apt install apache2
systemctl Gère les services sudo systemctl status ssh
uname Affiche des informations sur le système uname -a
Réseau
ip Affiche / configure les interfaces réseau ip a
ping Teste la connectivité avec une machine ping -c 4 8.8.8.8
ssh Se connecte à une machine distante ssh user@192.168.1.10
scp Copie des fichiers via SSH scp fichier.txt user@serveur:/tmp
Aide et divers
man Affiche le manuel d'une commande man ls
echo Affiche un texte echo "Bonjour"
history Affiche l'historique des commandes history
tar Crée ou extrait une archive tar -czf archive.tar.gz dossier/
