Introduction à CSS

CSS (Cascading Style Sheets) est un langage de style utilisé pour décrire la présentation d'un document HTML. Il permet de contrôler l'apparence visuelle des éléments d'une page web, tels que les couleurs, les polices, les marges et les dispositions.

CSS a été développé par le W3C (World Wide Web Consortium) et a été publié pour la première fois en 1996. Depuis lors, il a évolué pour inclure de nombreuses fonctionnalités avancées, telles que les animations, les transitions et les grilles.

L'utilisation de CSS permet de séparer le contenu d'une page web de sa présentation, ce qui facilite la maintenance et la mise à jour des styles. De plus, CSS permet d'appliquer des styles de manière cohérente sur l'ensemble d'un site web.

Les éléments principaux de CSS

  • Sélecteur : désigne les éléments à styliser (p, .classe, #identifiant)
  • Propriété : ce que l'on modifie (color, margin, font-family)
  • Valeur : la valeur donnée à la propriété (red, 20px)
  • Media query : règles qui s'appliquent selon la taille de l'écran (responsive)

Lier un fichier CSS à une page HTML

On place dans le <head> de la page une balise <link rel="stylesheet" href="chemin/vers/fichier.css">.

Exemple de code CSS

body {
    font-family: Arial, sans-serif;
    background-color: lightblue;
}

h1 {
    color: #333;
    text-align: center;
}

.menu a {
    color: white;
    text-decoration: none;
}

Explication du code

  • body Ellipsis : sélecteur de balise ; les règles s'appliquent à tout le corps de la page.
  • font-family : police de caractères (Arial, sinon n'importe quelle police sans empattement).
  • background-color : couleur de fond.
  • h1 Ellipsis : style du titre principal : couleur du texte et centrage.
  • .menu a : sélecteur de descendant ; cible les liens situés dans un élément de classe menu.
  • text-decoration: none : supprime le soulignement des liens.
